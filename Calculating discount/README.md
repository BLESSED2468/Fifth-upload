# Product Discount Calculator
    This is an E-commerce discount calculator that calculates the discount amount and final price of a product depending on what is been inputted by the user.
    

# What it does

    First it takes in user input for product name, original price, and discount percentage.

    It calculates the discount from the original price of the product purchassed

    Displays a structured "Purchase Summary" in the terminal

    Clean Output: Displays a structured, easy-to-read "Purchase Summary" in the terminal.

# How It Works

In the code we get the final price by using the logic: 

    Discount Amount = Discount Percentage/100 ​× (Original Price)

    Final Price = Price − Discount Amount
